# 함수 워크북 (웹) + 화면 이탈 알림

| 파일 | 역할 |
|---|---|
| `index.html` | 학생용 워크북 (디벗에서 열기) — S펜 필기, 화면 이탈 감지 |
| `teacher.html` | 교사용 현황판 — 학생별 상태, 이탈 알림, 기록 |
| `js/config.js` | **설정은 이 파일만 고치면 됩니다** (Firebase, 수업 코드, 판정 시간) |
| `firestore.rules` | Firebase 보안 규칙 |

## 1. 데모 모드 (참고)
`config.js`의 `FIREBASE_CONFIG`를 `null`로 바꾸면 데모 모드입니다. 같은 컴퓨터·같은 브라우저 안에서만 연결돼요.

1. VS Code에서 이 폴더를 열고 **Live Server**로 `teacher.html`을 엽니다.
2. 현황판의 "학생 페이지" 링크를 **새 창**으로 열어 로그인합니다.
3. 학생 창을 최소화하거나 다른 탭으로 옮겨 보면, 현황판에 바로 빨간 알림이 뜹니다.

## 2. Firebase — ✅ 설정 완료 (프로젝트 `math-workbook-b435f`, 서울)
이미 `js/config.js`에 연결돼 있습니다. 아래는 새 프로젝트로 다시 만들 때의 참고용 절차입니다.

1. https://console.firebase.google.com 에서 **프로젝트 만들기** (Google 애널리틱스는 꺼도 됨).
2. **빌드 > Authentication > 시작하기 > 로그인 방법 > 익명** 을 사용 설정.
3. **빌드 > Firestore Database > 데이터베이스 만들기** (위치: `asia-northeast3 (서울)`, 프로덕션 모드).
4. Firestore의 **규칙** 탭에 `firestore.rules` 내용을 붙여 넣고 게시.
5. **프로젝트 설정 > 내 앱 > 웹(</>)** 으로 앱을 추가하고, 나오는 `firebaseConfig` 값을 `js/config.js`의 `null` 자리에 붙여 넣기.
6. **Authentication > 설정 > 승인된 도메인**에 GitHub Pages 주소(`아이디.github.io`)를 추가.

## 3. GitHub Pages 배포
저장소에 폴더째 올리고 **Settings > Pages > Branch: main / (root)**. 
- 학생: `https://아이디.github.io/저장소/` 
- 교사: `https://아이디.github.io/저장소/teacher.html?c=1-3` (`c=` 뒤가 수업 코드)

## 4. 수업 운영 팁
- **반마다 다른 수업 코드**(예: 1-3, 1-4)를 쓰면 기록이 섞이지 않습니다. 수업이 끝나면 현황판의 "기록 초기화"(두 번 클릭).
- 현황판에서 **🔔 알림음 켜기**를 한 번 눌러야 소리가 납니다(브라우저 정책).
- 상태 뜻
  - **수업 중**: 워크북 화면을 보고 있음
  - **화면 이탈**: 다른 앱·다른 탭·홈 화면·화면 꺼짐 → 알림
  - **주의**: 화면은 보이지만 다른 창을 만지는 중(화면 분할 등) 3초 이상
  - **연결 끊김**: 35초 넘게 소식 없음(페이지를 닫았거나 와이파이 끊김)
- **필기 저장:** 펜을 뗄 때마다 1초 뒤 자동 저장됩니다(왼쪽 아래 `✓ 저장됨`). Firebase 모드에서는 서버에 저장되므로 디벗이 초기화되거나 다른 기기로 바꿔도 **같은 수업 코드·학번으로 로그인하면 그대로 복원**됩니다. 서버 연결이 끊기면 기기에 임시 저장하고 다시 연결되면 올립니다.
- **PDF 저장:** 상단 `📄 PDF` → '지금 Theme' 또는 '전체'. 문제 + 필기가 A4 PDF로 다운로드됩니다(파일명 `Function_Workbook_학번_….pdf`, 첫 줄에 학번·이름). 전체는 약 30쪽, 4~5MB, 만드는 데 10~30초.
- '기록 초기화'는 접속·이탈 기록만 지우고 **학생 필기는 지우지 않습니다.**

## 알아둘 한계
- 이탈을 **막지는 못하고 알려주기만** 합니다.
- 화면 분할로 워크북이 보이는 상태면 '이탈'이 아니라 '주의'로만 잡힙니다.
- 다른 기기(휴대폰) 사용은 알 수 없습니다.
- 학번·이름은 학생이 직접 입력하므로 남의 학번을 쓸 수 있습니다. 첫 수업에서 현황판 이름과 실제 학생을 한 번 대조해 보세요.
